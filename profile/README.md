<h3 align="center">Du suchst einen Job. jobpurr erledigt die Bewerbungen.</h3>

<p align="center">
Stellen finden, passende auswählen, Anschreiben schreiben, abschicken, Antworten im Blick behalten.<br>
Jeden Tag, ohne dass du zwanzig Tabs offen hast.
</p>

---

### So läuft es

```
 Finden  ─→  Prüfen  ─→  Schreiben  ─→  Senden  ─→  Mitlesen  ─→  Lernen
 alle        Fit 0–100   nur Fakten    Mail oder   Zusagen,      wird jede
 Börsen      pro Stelle  aus deinem    Karriere-   Absagen,      Woche
 + Alerts                Lebenslauf    portal      Einladungen   besser
```

| | |
|---|---|
| **Passend statt Masse** | Jede Stelle bekommt einen Fit-Wert. Nur was passt, geht raus. Die besten Stellen zuerst. |
| **Ehrlich** | Anschreiben enthalten nur, was in deinem Lebenslauf steht. Nichts wird erfunden. |
| **Du behältst die Kontrolle** | Ein Portal zeigt jede Bewerbung, jede Antwort und jede offene Aufgabe. Logins und heikle Klicks bleiben bei dir. |
| **Lernt mit** | Rückmeldungen von Firmen fließen zurück. Suchbegriffe und Auswahl passen sich jede Woche an. |
